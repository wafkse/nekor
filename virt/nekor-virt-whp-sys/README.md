# nekor-virt-whp-sys

## Overview

Windows WHP system interface

## Responsibilities

Provides low-level system interface bindings or representations for the WHP backend.

## Architecture

Intended to isolate Windows-specific interface details from shared virtualization contracts.

## Boundaries

It does not define backend-neutral architecture or guest ABI semantics.

## Status

The crate contains scaffolding only, system bindings remain planned.
