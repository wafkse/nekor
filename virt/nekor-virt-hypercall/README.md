# nekor-virt-hypercall

## Overview

Hypercall protocol

## Responsibilities

Defines guest/host hypercall protocol concepts independently of host frameworks.

## Architecture

Intended to specify shared call identities and protocol meanings for guest and host participants.

## Boundaries

It does not perform backend transport or implement KVM/WHP dispatch.

## Status

The crate contains scaffolding only, hypercall definitions remain planned.
